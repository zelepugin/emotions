# Алфавит эмоций и чувств

Интерактивный справочник: 86 эмоций, чувств и состояний - описание, сила 1-5, ощущения в теле, противоположности, поиск по части тела.

- Сайт: https://zelepugin.github.io/emotions/
- Работает как Telegram Mini App (тема и цвета Telegram, тактильный отклик) и как обычная страница (светлая/тёмная тема по системе).

Один файл: `index.html`, без сборки.

Основано на: «колесо эмоций» Р. Плутчика; L. Nummenmaa et al., «Bodily maps of emotions», PNAS, 2014.
